# Astro development sandbox

## About

簡易的な静的サイト向けの開発環境です。  
CMS等にアップロードや差分納品をしなければならないケースを想定し、ファイルのハッシュ化をしない構成にしています…🫠

## Getting Started

### Install dependencies

```bash
pnpm install
```

> Node.js（`^26`）と pnpm（`^12`）は `package.json` の `devEngines` で固定しています（`onFail: "error"`）。バージョンが合わない場合はインストール時にエラーになります。

### Start local server

```bash
pnpm dev
```

## Commands

スクリプト名は接頭辞で役割を分類しています。

| 接頭辞 | 役割 |
| --- | --- |
| `dev` | ローカル起動 |
| `build` | 納品生成 |
| `watch` | 監視（初回生成なし） |
| `create` | 生成 |
| `check` | 検証 |
| `format` | 整形 |
| `test` | テスト |
| `report` | ビルド成果物に対するレポート出力 |

| command         | detail                                                     |
| --------------- | ---------------------------------------------------------- |
| `dev`           | Development mode                                            |
| `build`         | Static site generation                                      |
| `preview`       | Preview the build output                                    |
| `check`         | Run all `check:*` in parallel                               |
| `check:ts`      | Type check (`tsc --noEmit`)                                 |
| `check:astro`   | Type check (`astro check`)                                  |
| `check:markup`  | MarkupLint (`src/**/*.astro`)                               |
| `format`        | ESLint & Stylelint & Prettier (auto fix, sequential)        |
| `test`          | Vitest (all projects with coverage)                         |
| `test:backend`  | Vitest (`scripts/node/__tests__` only)                      |
| `test:frontend` | Vitest (`src` only)                                         |
| `report:w3c`    | Build HTML then output W3C validation report                |
| `create:icon`   | Generate SVG data for Font Awesome                          |
| `plop`          | Create template files                                       |

`check` は `run-p "check:*"` で全メンバーを実行し、lint-staged 経由でコミットの度にも実行されます。そのため `check:*` に追加してよいのは、**静的解析であり、ファイルを書き換えないもの**に限ります。ビルドを伴う検証は `report:*` に置いてください。

`report:w3c` は HTML 検証に必要な工程（`build:astro` → `build:fonts` → `build:format:html`）だけを実行するため、事前の `pnpm build` は不要です。画像・SVG・JS の生成は HTML を変更しないため省略しています。

## Others

### Project config

プロジェクトの基本設定は`project.config.ts`を変更してください。  
[development settings](project.config.ts)

### Husky & lint-staged

Gitコミット時に`eslint`と`stylelint`、`prettier`が実行されます。

### SVG to Sprite

SVGからSpriteデータを生成します。  
対象データは下記に格納してください。  
`/src/assets/svg-sprite/*.svg`

### Font Awesome
`pnpm create:icon` を実行し、Font Awesomeのアイコン名（`house`など）を入力すると、JSONデータからSVGデータを生成します。  
アイコン名は下記から探してください。  
https://fontawesome.com/

また、有料ユーザーは`/scripts/node/data/icon-families.json`を有料版のjsonに差し替えると使用できます。

### W3C Validate

`build`後に`w3c`を行うことで、W3Cバリデーターのレポート`report-w3c.txt`が出力されます。  
必要に応じてHTML構文の確認と修正を行ってください。

## SKILLS

スキルは `.agents/skills/` に配置しています。各コーディングエージェント用のディレクトリからシンボリックリンクを張って参照してください。

```bash
mkdir -p .claude
ln -s ../.agents/skills .claude/skills
```

※ Codex の skills の配置が `.codex/skills` → `.agents/skills` に変更されています。（2026/3/12 現在）

| skill | detail |
| --- | --- |
| `this-code-modifier` | コードの修正・調整・最適化を、要件確認から実装・検証・レビューまで実施する |
| `this-code-reviewer` | 指定ファイルまたは差分をレビューし、根拠付きの指摘と改修案を提示する |
| `this-code-test-creator` | Vitest の単体テストを作成・更新する |
| `this-git-commit-writer` | 未コミット変更からコミット案（分割案を含む）を提案する |
| `this-github-issue-creator` | issue 案の作成から `gh issue create`・作業ブランチ作成まで行う |
| `this-github-pr-creator` | 差分を検証し、Draft でプルリクエストを作成する |
| `this-figma-image-exporter` | Figma の書き出し対象レイヤーをリネームし、Export 設定（2x / jpg）を適用する |

```
# プロンプト例
コミットを提案して
差分をレビューして
プルリクの作成をお願いします
```

プロジェクトの方針・規約は [AGENTS.md](AGENTS.md) を参照してください。
