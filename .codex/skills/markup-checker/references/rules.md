# A11y Checklist (Lite)

## Labels
- Inputs have `label` or `aria-label`
- `label` uses `for` + `id`

## Focus
- Visible focus styles
- Focus order is logical

## ARIA
- Use only when needed
- Ensure required attributes are present

## Headings
- Single `h1` per page
- No level skipping

## Keyboard
- All interactive elements are reachable
- No keyboard traps
